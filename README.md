# FlashCard_Demo

Android 7 - SDK 24 - JVM 17

Các chức năng của App:

1. Đăng ký, đăng nhập, đăng xuất, quản lý thông tin cá nhân Firebase Auth

2. Tạo, sửa, xóa bộ thẻ; phân loại theo môn học hoặc chủ đề(tạo nhiều list để người dùng tự nhập vào hoặc tạo list mới) Room, SQLite, Spring Boot

3. Import ra và gửi vào database

4. Lật thẻ, đánh dấu đã nhớ/chưa nhớ, làm bài trắc nghiệm và chấm điểm Java, Room, Spring Boot

5. Tạo câu hỏi bằng nội dung, trích xuất câu hỏi có sẳn từ trong file word, pdf

6. Lưu lịch sử ôn tập; thống kê điểm số và số lượng thẻ đã học; theo dõi tiến độ; lập lịch ôn tập và đồng bộ Google Calendar.(tạo luôn thông báo)
